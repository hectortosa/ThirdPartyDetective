THIRD PARTY SOFTWARE NOTICES AND INFORMATION
============================================================

ThirdPartyDetective

Turns the SBOM you already have into the third-party notices you ship.

This page is written the way TPD writes ATTRIBUTION.txt.

Install

Platforms:
linux-x64, linux-arm64, osx-arm64, osx-x64, win-x64. One executable with the .NET runtime bundled.
Source:
GitHub releases and the Homebrew tap only. Not published on nuget.org or any other registry.
Homebrew (macOS, Linux): 
brew install hectortosa/tap/thirdpartydetective
Download and verify (Linux, macOS): 
V=1.0.0 RID=linux-x64
base=https://github.com/hectortosa/ThirdPartyDetective/releases/download/v$V
curl -fsSLO "$base/thirdpartydetective_${V}_${RID}.tar.gz"
curl -fsSLO "$base/SHA256SUMS"
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf "thirdpartydetective_${V}_${RID}.tar.gz" thirdpartydetective
Windows (PowerShell; compare with SHA256SUMS): 
$V = "1.0.0"
$base = "https://github.com/hectortosa/ThirdPartyDetective/releases/download/v$V"
Invoke-WebRequest "$base/thirdpartydetective_${V}_win-x64.zip" -OutFile tpd.zip
(Get-FileHash tpd.zip -Algorithm SHA256).Hash.ToLower()
Expand-Archive tpd.zip -DestinationPath tpd
Pinned, for CI (keep the archive's hash in your repository): 
curl -fsSLO https://raw.githubusercontent.com/hectortosa/ThirdPartyDetective/v1.0.0/install.sh
TPD_VERSION=1.0.0 TPD_SHA256=<sha256 of the archive> bash install.sh
3.

Run

Input:
the SBOM of what you ship, for example a .NET publish directory, a Node.js project or a Python environment
trivy fs --format spdx-json --output sbom.spdx.json ./publish
thirdpartydetective --sbom sbom.spdx.json --mode distribution \
  --registry-fallback --format fulltext --include-license-text

Built for a legal document

ATTRIBUTION.txt travels with your product to customers. A wrong license, a missing text or a dropped component is a legal problem, so TPD is strict about evidence.

A.1As declared

Each package with its SPDX expression exactly as declared, like MIT OR Apache-2.0 or GPL-2.0-only WITH Classpath-exception-2.0, its copyright lines and its own license and NOTICE files.

A.2Never guessed

Vague declarations such as "BSD" or "Dual License" stay not determined. --fail-on-unresolved stops them from shipping until a decision is recorded in .tpd-overrides.json.

A.3Reproducible

The SPDX license list is bundled and registry answers can be pinned in a committed cache, so the same SBOM gives byte-identical reports on any machine.

A.4Untrusted by default

Names, URLs, copyright lines and license files are sanitized before they reach a report or a log. Network access goes only to the registries and public license hosts, with size and time caps.

A.5Policy for how you deploy

Every license is checked against your deployment mode, SaaS or distribution, using your own .tpd-policy.json when the defaults don't fit.

A.6One file to install

A single executable per platform, with its SBOM, checksums and build provenance. About 0.6 seconds for a 10,000-package SBOM.

From SBOM to notices

Point it at one or more SBOMs. Every step after that is deterministic.

  1. Step 1Read

    SPDX 2.2 and 2.3 from any of the usual tools, merged per package.

  2. Step 2Fill gaps

    Opt-in registry fallback for NuGet, npm and PyPI. It never replaces what the SBOM declares.

  3. Step 3Decide

    Decisions a person recorded for an exact package version win over everything else.

  4. Step 4Check

    Licenses against the deployment mode's policy, with violations reported.

  5. Step 5Write

    ATTRIBUTION.txt with an appendix of license texts, plus Markdown, JSON and HTML.

In CI

Run it after the build, on what you ship, from a committed registry cache with no network calls, and fail the job if a license is still undetermined.

trivy fs --format spdx-json --output app.spdx.json publish
thirdpartydetective --sbom app.spdx.json --mode distribution \
  --exclude-namespaces 'Contoso.*' \
  --registry-fallback --registry-fallback-cache .tpd-license-cache.json --offline \
  --format fulltext --include-license-text \
  --deterministic --fail-on-unresolved --output publish

Verify it

Every release file is attested by the workflow that built it from its tag, on a GitHub-hosted runner.

gh attestation verify thirdpartydetective_1.0.0_linux-x64.tar.gz \
  --repo hectortosa/ThirdPartyDetective

Configuration, overrides, the notice template and exit codes are in the README.
